# 🍪 간식뺏기 : STEALTH — Final

교실에서 시작해 복도 → 학생부실 → 정보실 열쇠 → 복도 → 정보실 → 간식 → 교실 귀환을 목표로 하는 고난도 잠입 게임입니다.

## 실행
```bash
pip install -r requirements.txt
streamlit run app.py
```

## GitHub + Streamlit Cloud
- `app.py`, `requirements.txt`를 GitHub 저장소에 업로드
- Streamlit Community Cloud에서 저장소 연결
- Main file path: `app.py`
- Deploy

## 조작
- WASD / 방향키: 이동
- SHIFT: 달리기
- SPACE: 가까운 책상/사물함 뒤에 숨기
- E: 열쇠/간식 획득
- ESC: 일시정지

## 들어간 시스템
- 4개 구역: 교실 / 복도 / 학생부실 / 정보실
- 3명의 순찰 선생님 AI와 서로 다른 시야각/거리/속도
- CCTV 3대와 회전 시야
- 벽/책상/사물함에 의한 시야 차단
- 경계도 / 소음 / 스태미나
- 달리면 소음 증가, 가까운 선생님에게 소음이 위험 신호가 됨
- 숨기 시스템
- 잠긴 문 + 정보실 열쇠
- 열쇠 획득 후 체크포인트 갱신
- 간식 획득 후 귀환 미션
- 발각 시 체크포인트 재시작
- PC 및 모바일 터치 조작
- 외부 이미지나 별도 게임 엔진 없이 Canvas로 동작

## 난이도 조절
`app.py`의 JavaScript에서 선생님 속도, 시야 범위, 시야각, 경계 증가량, CCTV 회전속도 등을 수정할 수 있습니다.

## EXTREME 난이도 업데이트

- 담임 선생님이 교실까지 순찰합니다.
- 선생님이 총 4명으로 증가했습니다.
- CCTV가 4대로 증가했습니다.
- 선생님 시야 범위/시야각/순찰 속도가 증가했습니다.
- 숨었을 때도 시야 감지가 완전히 사라지지 않습니다.
- 소음에 더 민감해졌습니다.
- 경계도 감소 속도가 느려졌습니다.
- 정보실 열쇠가 학생부실 안쪽 깊은 위치로 이동했습니다.
- 간식도 정보실 안쪽으로 이동했습니다.
